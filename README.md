# DEEP CIRCUIT

A retro raycaster dungeon crawler for the web. You are **RETROROM**, diving procedurally generated mainframe sectors in an endless descent.

## Play it

**https://retroromrunner.github.io/deep-circuit/**

No build step, no dependencies — just open the link in any modern browser, desktop or mobile.

## The mission

Each sector's uplink is firewalled. Collect **3 ACCESS SHARDS** to unlock it and descend deeper. Salvage **RAM, GPUs, and SSDs** as upgrades. Fight off **viruses, worms, trojans, and daemons**. Your hi-score persists in the browser — how deep can you go?

## Controls

- **W/S** or **↑/↓** — move forward / back
- **A/D** or **←/→** — turn
- Touch controls on mobile

## Tech

- Single self-contained HTML file — no dependencies, no build
- Canvas raycaster with procedural textures
- Procedural industrial soundtrack via Web Audio
- Hi-score saved in `localStorage`
